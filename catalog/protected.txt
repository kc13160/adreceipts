# Packages AdReceipts never touches, whatever a plan or catalog says.
# One name per line. A name ending in ".*" protects every package that starts
# with that prefix. Lines starting with # are comments.
#
# On top of this list, guard also refuses at run time:
#   - names containing bank, wallet, pay, auth or 2fa (unless a catalog entry
#     rates that exact package "safe"),
#   - the current holders of the home, dialer, SMS, browser and assistant
#     roles, the keyboard, the WebView provider, device admins and
#     accessibility services,
#   - any package not listed in a catalog file.
