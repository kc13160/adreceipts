# Device reports

A catalog entry can only be marked `tested` when it links to a device report:
a file here, or an https link to a public report.

Name files `<brand>-<model>-<YYYY-MM-DD>.md` and start from [TEMPLATE.md](TEMPLATE.md).
Remove everything personal first: no serial number, IMEI, account names,
phone number, notification content or unreviewed screenshots.
